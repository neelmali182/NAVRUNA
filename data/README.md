# NAVRUNA local data

- `ports/ports.json` — 279 curated real-world port locations used as simulation endpoints.
- `geography/land.geojson` — GSHHS intermediate-resolution coastline polygons packaged locally for land/collision simulation.
- `models/` — PPO checkpoints generated by the training UI; ignored by git because they are machine-specific artifacts.

Scenario files store SHA-256 fingerprints for the port and coastline files so an imported run can detect data mismatches. This directory currently does not include a complete upstream source/version/license manifest. Confirm the source terms and redistribution rights for both datasets before external or commercial distribution; do not infer a license from the fact that files are bundled.
